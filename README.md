# .github

OMSociety 的默认社区健康文件（default community health files）。

本仓库里的 `PULL_REQUEST_TEMPLATE.md`、`ISSUE_TEMPLATE/`、`CONTRIBUTING.md`、`SECURITY.md`、`CODE_OF_CONDUCT.md`
会对账号下**所有没有自带同名文件**的仓库自动生效（GitHub 平台机制，无需任何配置）。
某个仓库需要特殊化时，在该仓库放同名文件即覆盖本仓库的对应文件。

切分原则：本仓库只放**纪律层**（各仓库都成立的规则），具体命令、版本字段、已知边界等**事实层**由各仓库自己的 README / AGENTS.md / 模板补充。

机制文档：<https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file>
